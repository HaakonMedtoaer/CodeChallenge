      Set up GitHub sync
      
      
        
      
          Create a fine-grained personal access token at
          github.com/settings/personal-access-tokens,
          scoped to only this one repository, with Contents: read and write
          and nothing else. The token is kept in this browser's local storage and sent
          only to api.github.com.
        
      
        
      
          If the repository is public, so is the progress file. It holds exercise ids,
          timestamps and right/wrong marks — nothing sensitive — but if you would rather it
          were private, point the path below at a separate private repo.
